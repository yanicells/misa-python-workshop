# Your quiz files

Use the [workshop guide source](../web/src/content/docs/) for explanations and copyable code until the Vercel URL is added.

After cloning, start your own branch:

```bash
git checkout 00-start
git checkout -b my-quiz
```

Run commands from this `workshop` folder: `python3 quiz.py` on macOS or `py quiz.py` on Windows. Python 3.10 or newer is enough; there are no extra packages to install.
