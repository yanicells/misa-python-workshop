You finished a quiz, which means you already know enough Python to make decisions, repeat work, organize data, and split a program into functions. Pick something you want your next program to do, then learn the part of Python that helps you build it.

These lessons continue from the workshop for independent practice. Follow them in order or jump to the one your next project needs.

## Choose a route

| If you want to... | Start here |
| --- | --- |
| Change, copy, sort, or search groups of values | [More with collections](./collections/) |
| Clean names, split sentences, or control how output looks | [Work with text](./text/) |
| Stop a loop early, skip an item, or repeat by number | [Take control of loops](./control-flow/) |
| Turn one list into a new list | [Transform a list](./list-transformations/) |
| Make functions easier to reuse and debug | [Make functions predictable](./functions/) |
| Keep related data and behavior together | [Build your first class](./objects/) |
| Create a more specific version of an existing class | [Reuse with inheritance](./inheritance/) |
| Share your finished quiz through your own repository | [Put your work online](./publishing/) |

Classes and inheritance make more sense after you are comfortable with lists, loops, and functions. The other lessons can be taken in any order.

## How to use each lesson

Keep a `scratch.py` file for short experiments. Type the small examples, predict what they will print, then change one value and run them again. Reading code can make an idea feel familiar. Changing it shows whether you understand it.

When a lesson gives you a practice task, try it before opening a larger project. The task should take around ten to twenty minutes. It is fine if your version looks different from someone else's.

When you are ready to make something of your own, [pick a project](../projects/). Each project starts with a blank file and grows through working milestones. The pages describe the behavior without deciding every name, message, or feature for you.

## Keep one habit from the workshop

Run the program after every small change. If it stops working, the cause is probably in the few lines you just touched. Save a Git commit whenever a useful milestone works so you can experiment without losing that version.

The [official Python tutorial](https://docs.python.org/3/tutorial/) is a useful reference when you want more detail. It assumes some programming experience, so use it to look up one topic at a time.
