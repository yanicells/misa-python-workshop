You'll write a program that asks about the things you enjoy doing, adds points to MISA clusters, and shows your results. Then you can change a question and let a friend try it.

You don't need to know Python yet. Bring your laptop, and keep this guide open beside your editor. We have a [browser fallback](./setup/#use-colab-if-setup-gets-in-the-way) if local setup gets in the way.

## What we're making

Your finished quiz asks seven questions. There are no right answers. A choice adds one point to one or two clusters. Results show the top three score levels, including ties.

```text title="A sample result"
1. Events (tied) | 25.0% of quiz points
You might enjoy planning programs and sorting out event logistics.
1. HR (tied) | 25.0% of quiz points
You might enjoy helping members get to know each other.
```

The percentages describe the points your answers earned. This is a conversation starter about MISA, not a personality assessment or an application result.

The whole session is planned for 70 to 90 minutes, including introductions and closing. That's a pacing target; helpers can point you to a working checkpoint when you need one.

## Input, process, output

**Input:** you type an answer. **Process:** Python updates the cluster scores. **Output:** the terminal shows your results. We'll return to these steps whenever the code gets longer.

Saving your file, recording a Git commit, and publishing to GitHub are separate actions. You'll practice the first two as you build.
