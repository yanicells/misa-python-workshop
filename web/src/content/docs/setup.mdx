Start here as soon as you arrive. Setup can take a few minutes, and getting it out of the way means we can keep coding once the workshop begins.

Choose the section for your computer. Each one includes the full process, so you do not need to switch between Windows and macOS instructions. If you already installed a tool, its install command may tell you that it is already present.

<details>
<summary>Windows setup</summary>

### 1. Install Python, Git, and VS Code

Open **Windows Terminal** or **PowerShell** from the Start menu. [WinGet](https://learn.microsoft.com/windows/package-manager/winget/) comes with current versions of Windows 10 and 11. Run these commands one at a time:

```powershell
winget install --id Python.Python.3.13 -e
winget install --id Git.Git -e
winget install --id Microsoft.VisualStudioCode -e
```

Each command may ask you to accept an agreement or confirm the installation. Close the terminal when all three finish, then open it again so it can find the new programs.

### 2. Check the tools and add the Python extensions

```powershell
py --version
git --version
code --version
code --install-extension ms-python.python
code --install-extension ms-python.vscode-pylance
```

Python should report version 3.10 or newer. Git and VS Code should each print a version too.

### 3. Download and open the workshop

Run one command at a time. If you already cloned the repository, skip `git clone` and open your existing `misa-python-workshop` folder.

```powershell
git clone https://github.com/yanicells/misa-python-workshop.git
cd misa-python-workshop
git checkout 00-start
git checkout -b my-quiz
cd workshop
code .
```

`git clone` downloads the project. The two `checkout` commands load our starting point and create a personal branch named `my-quiz`. `cd` moves into a folder, and `code .` opens the current folder in VS Code.

### 4. Select Python in VS Code

In VS Code, press **Ctrl+Shift+P**, choose **Python: Select Interpreter**, and select the Python 3 version you checked earlier. Once `workshop` is open and Python is selected, your local setup is ready.

</details>

<details>
<summary>macOS setup</summary>

### 1. Install Homebrew, Python, Git, and VS Code

Open **Terminal** from Applications → Utilities. [Homebrew](https://brew.sh/) lets you install the workshop tools from the command line. Run its official installer:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

Read the prompts before confirming. When it finishes, Homebrew may print two **Next steps** commands for adding `brew` to your shell. Copy and run those commands before continuing.

Install the three tools:

```bash
brew install python git
brew install --cask visual-studio-code
```

### 2. Check the tools and add the Python extensions

Close and reopen Terminal, then run:

```bash
python3 --version
git --version
code --version
code --install-extension ms-python.python
code --install-extension ms-python.vscode-pylance
```

Python should report version 3.10 or newer. Git and VS Code should each print a version too.

### 3. Download and open the workshop

Run one command at a time. If you already cloned the repository, skip `git clone` and open your existing `misa-python-workshop` folder.

```bash
git clone https://github.com/yanicells/misa-python-workshop.git
cd misa-python-workshop
git checkout 00-start
```

`git clone` downloads the project. The two `checkout` commands load our starting point and create a personal branch named `my-quiz`. `cd` moves into a folder, and `code .` opens the current folder in VS Code.

The quiz uses only Python's standard library, so you do not need Python packages, Node.js, or the website dependencies. A [GitHub account](https://github.com/signup) is optional for the workshop. You only need one later if you want to publish your branch.

If a command fails, go to [troubleshooting](../help/). You can also use the Colab fallback below.

## If Git needs your name

Before your first commit, configure the name and email you want attached to this repository's commits:

```bash
git config user.name "Your Name"
git config user.email "YOUR_GITHUB_NOREPLY_EMAIL"
```

Replace the email text with the private commit email from your [GitHub email settings](https://github.com/settings/emails), or an email you're comfortable using. These settings identify commits; they don't sign you in.
