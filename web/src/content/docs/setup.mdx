## Install the three tools

Install [Python](https://www.python.org/downloads/), [Git](https://git-scm.com/downloads), and [VS Code](https://code.visualstudio.com/download). VS Code is where you'll edit text. Python runs it. Git records versions of your work. You can use another editor if you already have one.

Add Microsoft's [Python extension](https://marketplace.visualstudio.com/items?itemName=ms-python.python) to VS Code. It helps VS Code recognize Python files, run programs, and point out common mistakes. [Pylance](https://marketplace.visualstudio.com/items?itemName=ms-python.vscode-pylance) adds clearer code suggestions and error hints. The Python extension may install it for you.

After installing Python, open VS Code's Command Palette with **Ctrl+Shift+P** on Windows or **Cmd+Shift+P** on macOS. Choose **Python: Select Interpreter**, then select the Python 3 installation you just checked.

Open a terminal in VS Code with **Terminal → New Terminal**. A terminal accepts commands. Type one command and press Enter. Wait for it to finish before entering the next one. If you see Python's `>>>` prompt, type `exit()` to return to the terminal.

## Check the installations

On Windows, run one line at a time:

On Windows, check:

```powershell
py --version
git --version
```

On macOS, run:

```bash
python3 --version
git --version
```

The first command should report Python 3.10 or newer. The second should print a Git version. The quiz uses only Python's standard library, so you do not need to install Python packages. You also do not need Node.js or the website dependencies.

Create a [GitHub account](https://github.com/signup) before the event if you want to publish your work later. Cloning a public repository doesn't require an account.

## Get the project

If you already cloned the repository, open that folder and skip to **Open the starter checkpoint**. Do not clone a second copy into the same folder.

### 1. Download the repository

Use `cd` to move to a folder where you keep projects. Then run:

```bash
git clone https://github.com/yanicells/misa-python-workshop.git
```

`git clone` downloads the files and their Git history into a new `misa-python-workshop` folder.

### 2. Enter the project folder

```bash
cd misa-python-workshop
```

`cd` means change directory. A directory is a folder. Your terminal now runs commands inside the repository.

### 3. Open the starter checkpoint

```bash
git checkout 00-start
```

This loads our prepared starting version. A branch is a named line of work in Git.

### 4. Make your own branch

```bash
git checkout -b my-quiz
```

The `-b` option creates a branch and switches to it. Keep your changes on `my-quiz` during the workshop. The numbered branches stay available as working references.

### 5. Enter the workshop folder

```bash
cd workshop
```

This folder contains the Python files you will edit.

## Run the starter

Open the repository folder in VS Code with **File → Open Folder**. Select `workshop/quiz.py`. On macOS, run:

```bash
python3 quiz.py
```

On Windows:

```powershell
py quiz.py
```

You should see `Your MISA quiz starts here.` If the command fails, go to [troubleshooting](../help/) or use Colab below. Once it works, continue to [welcome the player](../build/welcome/).

## If Git needs your name

Before your first commit, configure the name and email you want attached to this repository's commits:

```bash
git config user.name "Your Name"
git config user.email "YOUR_GITHUB_NOREPLY_EMAIL"
```

Replace the email text with the private commit email from your [GitHub email settings](https://github.com/settings/emails), or an email you're comfortable using. These settings identify commits; they don't sign you in.
